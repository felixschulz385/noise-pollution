## Decision

The project follows [research-project-template](https://github.com/felixschulz385/research-project-template)
at commit `ee56108` (`.copier-answers.yml`; `copier update` pulls later changes). Adopted:

- **Package.** `src/` is no longer the package: the code is `src/noise_pollution/` (`core/`,
  `regions/`, `cli/`, `config/`, `analysis/`), installed editable and imported as
  `from noise_pollution… import …`. The console script `noise_pollution` (and
  `python -m noise_pollution`) replaces `python -m src.cli`.
- **Lines of work.** Three lines, each with a charter in [`../lines/`](../lines/):
  `sweden-schools`, `florida-schools` and `sweden-residents`. Their notebooks are in
  `notebooks/<line>/`, numbered across the project in the order the work was done (the source
  walkthroughs from `src/experiments/` and the analysis notebooks from `output/notebooks/`).
  Florida's figures moved to `output/figures/florida-schools/`.
- **Docs.** Every doc under `docs/` carries front matter; the tables in `docs/README.md`,
  `README.md` and `AGENTS.md` are generated by `scripts/docs.py`, which the pre-commit hook and CI
  run. The Florida within-barrier plan moved to the florida-schools line's notes.
- **Repository.** The template's hooks (notebook outputs, restricted data, docs check), CI (docs,
  ruff, pytest), `.gitignore`, `pyproject.toml` (console script, ruff) and `environment.yml`
  (env `noise_pollution`), locked in `conda-lock.yml` for osx-64 (the Intel Mac it runs on) and
  linux-64 (CI) instead of the template's osx-arm64. Ruff runs with the template's rule set; adopting it found one real bug,
  a missing `Path` import in Sweden's `noise_barriers/fetch.py`.
- **Tests** keep mirroring the package; test files whose basenames collided between the two
  regions carry the region (`test_sweden_panel_assemble.py`), so pytest collects them without
  `--import-mode=importlib`.
- **Agent instructions** in `AGENTS.md`; `CLAUDE.md` imports it.
- **Config.** One unified `orchestration/configs/noise_pollution.yaml` with `data_root` and a
  block per region, read by `noise_pollution.config.settings`; per-machine values in
  `noise_pollution.local.yaml` (git-ignored).

Deliberate deviations from the template:

| Template | Here | Why |
|---|---|---|
| `src/<package>/data/sources/<source>.py`, one registry | `src/noise_pollution/regions/<region>/sources/<source>/` | Two independently built pipelines ([`01-multi-region-layout.md`](01-multi-region-layout.md)); a `region` layer above the sources stays. |
| `<package> data <verb> --source <name>` | `noise_pollution <region> data <source> <stage>` | The shape the pipelines were built with; changing it waits for the registry below. |
| Data root `data_nobackup/` | `data/` in the repository (`data_root: data`) | 23,797 files already there, in OneDrive; nothing moves. |
| Branch `main`, lines on `line/<slug>` | `master`; work so far on `master` | Renaming the default branch is outward-facing; new line work branches as `line/<slug>`. |
| Pre-specs before each step | none yet | The analyses so far ran before this rule; the charters say so, and the next step of each line starts with a pre-spec. |
| `results.md` per line | the Summary of each line's analysis notebook | Moving the record out of the notebooks is the first item of the open delta. |

Open delta, in rough order:

1. A `results.md` per line, written from the analysis notebooks' Summary sections.
2. Pre-specs for the next step of each line (`python scripts/docs.py new prespec <line> <name>`).
3. The specification (outcome, treatment tier, controls, clusters) from the analysis notebooks
   into `noise_pollution/analysis/spec.py` and a module per line.
4. A `DataSource` base class with `STEPS`/`REQUIRES`, a per-region registry, `data summary` /
   `data verify`, and argparse defaults moved into the `regions` blocks of the unified config.
5. The grid export's per-machine path (`~/Dropbox/…` in `grid/shared.py`) into the local config.

## Reasoning

The template now organises research by line of work, generates every status table and checks the
docs in CI, none of which the project had. The region layer and the per-stage CLI work and are
covered by about 680 tests; rewriting 25 sources into `DataSource` classes in the same change
would have mixed a mechanical move with a redesign of tested code.

## Rejected alternatives

- **The full port at once** (`DataSource` classes, registry, config-driven defaults): larger and
  riskier; kept as open delta item 4.
- **Lines by country** (`sweden`, `florida`) or **one line**: the Sweden school design, the
  Florida school design and the individual-level register design each have their own question,
  data and record.
- **Renaming the data root to `data_nobackup/`**: no gain on this machine, a large OneDrive
  re-sync.

## Consequences

- Imports change from `src.…` to `noise_pollution.…`; commands from `python -m src.cli …` to
  `noise_pollution …`. Notebooks find the root by `pyproject.toml` and put `src/` on `sys.path`
  when the package is not installed.
- The tree before the port is tagged `archive/2026-11-pre-template-port`.
- Notebook paths changed (`output/notebooks/sweden/analysis.ipynb` is
  `notebooks/sweden-schools/20_analysis.ipynb`); their outputs are from runs before the move.
