# Sweden — data sources

Index of every data domain in the Sweden pipeline. Each gets its own page at
`docs/data/sweden/<source>/README.md` once the per-region source registry
(template `docs/02`, see also [`../../design/01-multi-region-layout.md`](../../design/01-multi-region-layout.md))
is in place; until then this table is maintained by hand from
`src/regions/sweden/cli.py` and the modules under `src/regions/sweden/sources/`.

| Domain | Steps implemented | Prerequisites | Module |
|---|---|---|---|
| `timetable` | `fetch`, `preprocess` (`assemble` stubbed) | — | `src/regions/sweden/sources/timetable/` |
| `stations` | `fetch`, `preprocess` (`assemble` stubbed) | — | `src/regions/sweden/sources/stations/` |
| `network` | `preprocess`, `assemble` (`fetch` is a manual-download warning), plus `preprocess-tracks` (new 2026-09-15: the fine-grained open-track candidate network, 187,882 rows/269 routes, feeding `schools`' algorithms 4/5) | `stations.preprocess` for the overlay plot | `src/regions/sweden/sources/network/` |
| `noise_barriers` | `list-files`, `fetch`, `preprocess` — `built_year` now cleaned of Trafikverket's per-kind "unrecorded" sentinel (`1900` road / `0` rail), fixed 2026-09-15 while building `schools assemble` (was silently corrupting ~51% of road barriers' years); a broken import in `save_processed_noise_barriers` fixed at the same time; rail's `distance_from_track_center_m` `999` "not recorded" sentinel cleaned 2026-09-23. **Barrier geometry sits on the road/track centreline** (road 99.8%, rail 99.7%) and `side` carries no signal -- see [`barrier_matching.md`](barrier_matching.md) | — | `src/regions/sweden/sources/noise_barriers/` |
| `schools` | `fetch`/`preprocess` for the `Skolenhetsregistret` directory (identity, geocoding, grade span, operator), `assemble` (school↔barrier point match, algorithms 1-2), plus `assemble-rail-network`/`assemble-road-network` (algorithms 4-5, `same_route`/`same_side` via the rail/road networks — road's `same_side` was unreliable via rail's signed-offset method (2026-09-15), then rebuilt 2026-09-23 on the shared `_barrier_reference.py` (exact link-key join, side from OSM walls / a road alongside / unknown, never defaulted), see [`barrier_matching.md`](barrier_matching.md) and [`schools/README.md`](schools/README.md)) | `noise_barriers` (`assemble`), `barrier-protection build` (`assemble-*-network`) | `src/regions/sweden/sources/schools/` |
| `assessments` | `fetch`/`preprocess` for both achievement-data vintages, now run at **full national scale** (2026-09-16): live PxWeb `kvalitetssystem` API (5,238 schools x 51 measures x 4 läsår = 1,068,552 rows, 2022/23–2025/26) and the archived SIRIS exports (`slutbetyg_arskurs9` 34,666 rows/3,070 schools + `salsa` 29,971 rows/2,542 schools, 1998–2019, no gaps) — see [`assessments/README.md`](assessments/README.md). Two real bugs found and fixed running the full fetch: PxWeb's undocumented POST rate limit (fixed with retry/backoff) and a stale smoke-test batch file silently poisoning the resume logic (fixed with cached-batch coverage validation). Split out from `schools` 2026-09-15 (mirrors Florida's `schools` vs. `assessments` separation) | `schools` (join key only, no crosswalk needed) | `src/regions/sweden/sources/assessments/` |
| `road_network` | `preprocess` (new 2026-09-15: NVDB `Vägtrafiknät`, manually downloaded via Lastkajen — no `fetch`, same manual-download pattern as rail `network`). 2,080,116 current `bilnät` road segments, feeding `schools`' road algorithms 4/5 — see [`road_network/README.md`](road_network/README.md) | — | `src/regions/sweden/sources/road_network/` |
| `skolkoll` | `fetch`/`preprocess` (a third-party Skolverket aggregator, skolkoll.se) — used narrowly to recover real WGS84 coordinates for schools purged from the live `Skolenhetsregistret` entirely (its own `status=UPPHORT`, which our own registry fetch never sees). 21,843 rows, 12,017 with a real 8-digit `skolenhetskod`. Feeds `panel/vanished_recovery.py`'s `recover-vanished-schools` stage — see [`skolkoll/README.md`](skolkoll/README.md) and [`schools/README.md`](schools/README.md)'s "Vanished pre-registry schools" section | `schools` (for the vanished-code population), `assessments` (for SIRIS identity) | `src/regions/sweden/sources/skolkoll/` |
| `osm_walls` | `fetch`, `preprocess` (new 2026-09-23: OpenStreetMap walls via Overpass -- 510 tagged noise barriers + 7,659 untyped `barrier=wall`, 561 km -- the one direct observation of which side of its road a noise barrier stands on; covers ~18% of school-relevant road and ~8% of rail barriers, see [`barrier_matching.md`](barrier_matching.md)) | — | `src/regions/sweden/sources/osm_walls/` |
| `barrier_protection` | `build` (new 2026-09-24: every barrier's road stretch, side (`side_method`) and protected area, computed once in ~2.5 min for all of Sweden and saved, instead of rebuilt by each consumer. Writes `protection_zones.parquet`, a **national protection layer**: one polygon per barrier, usable with a spatial join for any unit of analysis. See [`barrier_protection/README.md`](barrier_protection/README.md) and [`barrier_matching.md`](barrier_matching.md)) | `noise_barriers`, `road_network`, `network` (tracks), `osm_walls` | `src/regions/sweden/sources/barrier_protection/` |
| `panel` | `assemble` (joins `assessments` + `schools assemble`'s road/rail x point/same_route/same_side treatment timing + `traffic`'s real multi-vintage ÅDT history + `neighbourhood`'s income/education/employment panel into one long `event_study_panel.parquet`) — implemented and run. Also picks up `panel/vanished_recovery.py`'s Skolkoll-recovered coordinates (optional — `sweden data panel recover-vanished-schools`, run before `assemble`): 306 previously-hard-coded-`False` vanished schools get real treatment status instead, raising `road_point`/`road_same_route` ever-treated-schools from 233/180 to 273/211 and `rail_point`/`rail_same_route`/`rail_same_side` similarly. **Grain is long** (`skolenhetskod x year x era x outcome_name`): a 2026-09-17 decision deliberately excludes `kvalitetssystem` from this assembly (its nearest conceptual analogue to `meritvärde` is a binary pass-rate share, not a continuous score, and the 2020-21 legal-suppression notch means it doesn't even abut the SIRIS era — see `panel/assemble.py`'s module docstring), so this table is now **SIRIS-only** (era `siris`); within SIRIS, `stitch_meritvarde` z-scores each side of the 2014/15 grading-scale reform separately into one continuous `meritvärde_z` series. Traffic is joined by real **interval overlap** (each outcome row's own year matched against whichever historical ÅDT window actually covers it); neighbourhood by a plain `(skolenhetskod, year)` merge (new 2026-09-17 — DeSO boundaries don't move year to year, so no interval logic is needed there). Real run: **437,948 rows, 2,651 distinct schools, 1998–2019** (SIRIS's own span). 146,596 rows (33.5%) have a real traffic match (1,023 schools); 152,768 rows (34.9%, 1,672 schools) have a real neighbourhood match — **but its `employment_rate` column is 0% real everywhere in this panel**: employment's own real coverage floor (2020) never overlaps SIRIS's 1998-2019 span at all, confirmed directly, not a bug — income (real floor 2011) and education (real floor 2015) both do overlap and show real values. No `fetch`/`preprocess` of its own | `assessments` (`preprocess-siris`), `schools` (`assemble`, `assemble-rail-network`, `assemble-road-network`), `traffic` (`assemble`), `neighbourhood` (`assemble`) | `src/regions/sweden/sources/panel/` |
| `traffic` | `preprocess`, `assemble` (new 2026-09-16: NVDB `Trafik` — ÅDT + CNOSSOS-EU-ready time-of-day x vehicle-class splits, Covariate Cluster C, manually downloaded via Lastkajen — no `fetch`). **A real multi-vintage historical panel, not a single snapshot** — `Betraktelsedatum` genuinely returns each segment's historical `[valid_from, valid_to)` measurement window (confirmed live 2026-09-16 after an earlier same-session test wrongly concluded otherwise, see `traffic/README.md`'s "Correction"). `preprocess` unions every order placed so far (8 as of 2026-09-16: 1999/2003/2007/2011/2015/2019/2022/2026) → 295,696 distinct windows, 77,485 elements, spanning 1984–2026. `ELEMENT_ID` also confirmed to join `road_network`'s `element_id` directly (100% overlap), unused but available. `assemble` matches schools to their nearest segment (8,629/9,520, 90.6%, within 1000m) then attaches that segment's full window history (45,628 history rows total) — see [`traffic/README.md`](traffic/README.md). Joined into `panel` via a real interval-overlap-by-year match | `schools` (`preprocess`, for coordinates) | `src/regions/sweden/sources/traffic/` |
| `neighbourhood` | `fetch-boundaries`/`preprocess-boundaries` + `fetch-{income,education,employment}`/`preprocess-{income,education,employment}` + `assemble` (new 2026-09-17: SCB DeSO-grain small-area statistics, Covariate Cluster F, all three planned subsources). Boundaries via SCB's geoserver WFS (`stat:DeSO_2018`, genuinely slow — ~90s/500 features, ~15-20 min for the whole country, no simplified layer exists), income/education/employment via SCB PxWebApi (`Tab2InkDesoRegso` mean net income, `UtbSUNBefDesoRegso` post-secondary education share, `ArRegDesoStatusN` employment rate — one shared batched-by-region fetch helper). **DeSO was redrawn in 2025** (`DeSO_2018`: 5,984 areas vs. `DeSO_2025`: 6,160) — this module uses the 2018 vintage throughout, which caps real coverage at 2023 for all three tables (income/employment 100% suppressed for 2024 under 2018-vintage codes; education's 2024-2025 successor table has no DeSO2018 codes at all). Real run: 5,984 areas / 290 kommun (exact match to Sweden's real municipality count) matched to schools by **point-in-polygon** (not nearest-segment like every other module here) — 9,519/9,520 schools (99.99%) matched, the one failure a real upstream geocoding error, not a distance-cutoff miss. 133,267 panel rows, the three subsources outer-merged on `(desokod, year)` — see [`neighbourhood/README.md`](neighbourhood/README.md). Joined into `panel` 2026-09-17 via a plain `(skolenhetskod, year)` merge (no interval logic needed, unlike `traffic`) | `schools` (`preprocess`, for coordinates) | `src/regions/sweden/sources/neighbourhood/` |
| `grid` | `preprocess` + `assemble` (new 2026-09-22: a **second output spec** alongside `schools` — same barrier layers, matched to a self-built 100m x 100m grid cell instead of a school, assigning `ever_near_{100,200,500,1000}m` treated/untreated flags. SCB's real 100m register grid is restricted MONA microdata, not open — researched live 2026-09-22, see [`grid/README.md`](grid/README.md) — so this builds its own 100m tiling, aligned to the same SW-corner-keyed convention SCB's/INSPIRE's real grids use, within a 1000m buffer of any barrier only (694 disjoint components, not a nationwide 45M-cell grid)). Real run: 400,369 cells; road `ever_treated` (≤1000m) 271,116, rail 145,286 | `noise_barriers` (`preprocess`), `barrier-protection build` (`assemble`) | `src/regions/sweden/sources/grid/` |

On-disk output lands under `data/sweden/<domain>/{raw,processed,assembled}/`.

**Control variables for the main analysis** (traffic, road-works,
neighbourhood, shocks, staff, air co-pollution) and the source modules that
would supply them are catalogued in [`covariates.md`](covariates.md).
Traffic (Cluster C) and neighbourhood (Cluster F: income, education,
employment) are built and run; the rest remain research only as of
2026-09-17.
